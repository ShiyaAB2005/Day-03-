# Day 03 - Data Analysis & Python for AI/ML

## Objective

The objective of this task is to clean, analyze and visualize a facility dataset using Python.

## Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib

## Dataset

The dataset contains information about:

- Facility ID
- Location
- Cleanliness Score
- Odor Score
- Waste Level
- Water Availability
- Footfall
- Inspection Date
- Outdoor Conditions

## Data Cleaning

The dataset was checked for:

- Missing values
- Duplicate records
- Incorrect date formats

Duplicate records were removed and the inspection date was converted into the correct date format.

## Data Analysis

The following statistics were calculated:

- Average cleanliness score
- Minimum and maximum cleanliness score
- Waste level statistics
- Water availability
- Footfall statistics
- Location-wise cleanliness
- Location-wise footfall
- Correlation between cleanliness and footfall

## Visualizations

The following visualizations were created:

1. Average Cleanliness Score by Location
2. Average Footfall by Location
3. Cleanliness Score Histogram
4. Footfall vs Waste Level Scatter Plot
5. Water Availability Pie Chart

## Key Findings

1. Higher footfall generally results in higher waste levels.
2. Cleanliness scores vary between different locations.
3. Some facilities have poor outdoor conditions and higher waste levels.
4. Most facilities have water availability.
5. Footfall differs significantly across locations.

## Conclusion

The analysis demonstrates how Pandas can be used for data cleaning and analysis and Matplotlib can be used to visualize useful patterns in real-world data.
